# Raqam — разработка сайтов и цифровизация бизнеса

Сайт студии Raqam (Ташкент): реальные проекты, отраслевые решения с рабочими демо, услуги и форма заявки.
Статический сайт без сборки: HTML, CSS и JavaScript, плавная прокрутка на [Lenis](https://github.com/darkroom-engineering/lenis) (MIT, лежит в `assets/vendor`).
Все пути относительные, поэтому `index.html` открывается и с диска, и с любого хостинга.

## Структура

```
index.html            главная: проекты, отраслевые решения, цифровизация, услуги, процесс, партнёры, вопросы, заявка
styles.css            стили главной
main.js               анимации, курсор, окна кейсов (тексты кейсов — в объекте CASES), форма
demos/oshxona/        демо-сайт ресторана
demos/tong-coffee/    демо-сайт кофейни
demos/burger-lab/     демо-сайт доставки
demos/kiyim/          демо интернет-магазина одежды
assets/work/          скриншоты и видео проектов
assets/partners/      логотипы партнёров
vercel.json           настройки Vercel (статический сайт из корня)
```

Реальные проекты: сайт Национального оркестра Филармонии Узбекистана (для Министерства культуры), Scopos, сайт Scopos, Scopos Route.
Четыре демо — концепты с вымышленными заведениями; их функции работают, но ничего никуда не отправляют.

## Как поменять

- **Ссылка на сайт оркестра.** В `main.js`, в `CASES.orchestra.links`, добавьте `{ href: 'https://…', label: 'Открыть сайт' }`.
- **Куда приходят заявки.** `FORM_ENDPOINT` в начале `main.js` (FormSubmit). При первой заявке с нового домена FormSubmit присылает письмо с подтверждением — его нужно открыть один раз.

## Локальный запуск

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Деплой на Vercel

1. vercel.com → **Add New… → Project** → импортируйте репозиторий `sajaboy15/site_portfolio`.
2. Framework Preset — **Other**, Build Command и Output Directory оставьте пустыми (всё задано в `vercel.json`).
3. **Deploy**. Дальше каждый push публикуется автоматически.
