# SAJA BOYS — портфолио

Сайт-портфолио студии SAJA BOYS для ресторанов, кафе, доставки и магазинов.
Статический сайт без сборки: HTML, CSS и JavaScript, плавная прокрутка на [Lenis](https://github.com/darkroom-engineering/lenis) (MIT, лежит в `assets/vendor`).

## Структура

```
index.html            главная: hero, концепты, «зачем сайт», услуги, процесс, вопросы, форма заявки
styles.css            стили главной
main.js               анимации, курсор, кейсы (окно с описанием проекта), форма
demos/oshxona/        демо-сайт ресторана узбекской кухни
demos/tong-coffee/    демо-сайт кофейни
demos/burger-lab/     демо-сайт доставки бургеров
demos/kiyim/          демо интернет-магазина одежды
assets/work/          скриншоты демо-сайтов для карточек
vercel.json           настройки Vercel (статический сайт из корня)
```

Все четыре демо — концепты с вымышленными заведениями; функции (меню, корзина, бронь, оформление) работают,
но ничего никуда не отправляют.

## Форма заявки

Заявки с главной уходят на почту через FormSubmit — адрес задан в `FORM_ENDPOINT` в начале `main.js`.
При первой заявке с нового сайта FormSubmit может прислать письмо с подтверждением — его нужно открыть один раз.

## Локальный запуск

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Деплой на Vercel

1. vercel.com → **Add New… → Project** → импортируйте репозиторий `sajaboy15/site_portfolio`.
2. Framework Preset — **Other**, Build Command и Output Directory оставьте пустыми (всё задано в `vercel.json`).
3. **Deploy**. Дальше каждый push в ветку публикуется автоматически.

Или из терминала: `npx vercel --prod`.
